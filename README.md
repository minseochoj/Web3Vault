## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3Vault.git`
2. `cd Web3Vault`
3. Install in editable mode: `pip install -e .`

## Configuration

Web3Vault is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
